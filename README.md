# Number Guessing Game

A command-line number guessing game built in Python. The computer picks a random number and you try to guess it.

Project link: https://roadmap.sh/projects/number-guessing-game.

## Requirements

- Python 3.x

## How to run

```
git clone https://github.com/teaguec/number-guessing-game.git
cd number-guessing-game
python number_guessing.py
```
